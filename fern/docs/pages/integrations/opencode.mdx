[OpenCode](https://opencode.ai) is an open-source AI coding agent with terminal, IDE, and desktop interfaces. It supports custom OpenAI-compatible providers via the `@ai-sdk/openai-compatible` package, so it works with `neural-private` out of the box.

## Compatibility

| Feature | Status | Notes |
|---|:---:|---|
| Chat & streaming | ✅ | |
| Tool use / function calling | ✅ | Model-dependent |
| File tools (read, write, edit) | ✅ | Managed by OpenCode |
| MCP servers | ✅ | Configured in OpenCode |
| Multi-session agents | ✅ | |
| Images | ❌ | Not supported |

---

## Prerequisites

- OpenCode installed — see [opencode.ai](https://opencode.ai)
- `neural-private` server running (see [serve](/configuration/cli#serve))

---

## Run

`neural-private run` generates a config file at `~/.config/opencode/neural-private.json`, sets `OPENCODE_CONFIG` to point at it, and launches OpenCode:

```bash
neural-private run opencode
```

The server is started automatically if it is not already running. Pass `--no-server` to skip that check when the server is managed externally.

**With a specific model:**

```bash
neural-private run opencode --model my-model
```

On first launch, press `Ctrl+P` → **Switch Model** → select the model under **Neural-Private**.

## Manual setup

If you prefer to manage the configuration yourself:

**1. Create the config file**

Create `~/.config/opencode/neural-private.json` (a separate file to avoid overriding your default OpenCode config):

```json
{
  "$schema": "https://opencode.ai/config.json",
  "provider": {
    "neural-private": {
      "npm": "@ai-sdk/openai-compatible",
      "name": "Neural-Private",
      "options": {
        "baseURL": "http://localhost:8080/v1",
        "apiKey": "secret-key"
      },
      "models": {
        "default": {
          "name": "Neural-Private - default",
          "limit": {
            "context": 8096,
            "output": 1024
          }
        }
      }
    }
  }
}
```

Replace `secret-key` with the value of `server.auth.secret` from your `neural-private` settings. If auth is disabled, any non-empty string works.

**2. Launch with the custom config**

```bash
export OPENCODE_CONFIG=~/.config/opencode/neural-private.json
opencode
```

On first launch, press `Ctrl+P` → **Switch Model** → select the model under **Neural-Private**.
