This is the recommended installation method for developers who want to run Neural-Private against an existing LLM server (Ollama, LM Studio, etc.) without cloning the repository.

<Note>
  Neural-Private package files are hosted at `https://wheels.Neural-Private.dev/packages/`. `uv` uses that location to find the Neural-Private release and continues to resolve public dependencies from PyPI by default.
</Note>

---

## Install

<Tabs>
  <Tab title="macOS (Homebrew)">
    ```bash
    brew tap zylon-ai/tap
    brew install neural-private
    ```

    Upgrade:
    ```bash
    brew upgrade neural-private
    ```
  </Tab>
  <Tab title="uv (recommended, any platform)">
    [`uv`](https://docs.astral.sh/uv/) installs Neural-Private in an isolated environment and puts the `neural-private` CLI on your path.

    ```bash
    # Install the core package
    uv tool install  --python 3.11 \
      --find-links https://wheels.Neural-Private.dev/packages/ \
      "neural-private[core]"
    ```

    Install `uv` first with the official standalone installer from `astral.sh/uv`.

    Add explicit extras only when needed, for example `neural-private[core,queue]`.

    Upgrade:
    ```bash
    uv tool upgrade \
      --find-links https://wheels.Neural-Private.dev/packages/ \
      neural-private
    ```
  </Tab>
</Tabs>

<Note>
  **Python 3.11 is required.** Neural-Private does not support Python 3.10 or 3.12+.
</Note>

## Verify

<Tabs>
  <Tab title="macOS / Linux">

## Run

After installing, set `OPENAI_API_BASE` to your LLM server and start:

<Tabs>
  <Tab title="macOS / Linux">
    ```bash
    OPENAI_API_BASE=http://localhost:11434/v1 neural-private serve
    ```
  </Tab>
  <Tab title="Windows (PowerShell)">
    ```powershell
    $env:OPENAI_API_BASE = "http://localhost:11434/v1"
    neural-private serve
    ```
  </Tab>
  <Tab title="Windows (CMD)">
    ```cmd
    set OPENAI_API_BASE=http://localhost:11434/v1
    neural-private serve
    ```
  </Tab>
</Tabs>

Neural-Private starts on port `8080` by default. Change it with `neural-private serve --port <port>`.

## Data storage

All application data (vector store, ingested documents, models, caches) is stored under a single home directory:

| Platform | Default path |
|---|---|
| macOS / Linux | `~/.local/share/neural-private/` |
| Windows | `%LOCALAPPDATA%\neural-private\` |
| Docker | `/home/worker/app/` (fixed) |

Override the location with `PGPT_HOME`:

```bash
PGPT_HOME=/data/neural-private neural-private serve
```

## Key environment variables

| Variable | Default | Description |
|---|---|---|
| `OPENAI_API_BASE` | `https://api.openai.com/v1` | Base URL of your OpenAI-compatible LLM server |
| `OPENAI_API_KEY` | _(empty)_ | API key, if your server requires one |
| `OPENAI_EMBEDDING_API_BASE` | same as `OPENAI_API_BASE` | Override for the embeddings endpoint |
| `PORT` | `8080` | Port the server listens on (also settable via `neural-private serve --port`) |
| `PGPT_HOME` | `~/.local/share/neural-private` | Root directory for all local data (vector store, models, caches) |
| `PGPT_LLM_AUTO_DISCOVER_MODELS` | `true` | Discover LLM models from `/v1/models` on startup |
